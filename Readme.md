Role 3: Client-Side Programmer(s)
The team member(s)*

who take this role will be responsible for the implementation of the
client-side components. The clients must implement a mechanism for allowing user
interaction with the server. This will require -
 Forming a connection to the server (based on configuration data, e.g. IP addr/port)
 Taking input from the user, then parsing and interpreting these so they can be passed to the
server in the correct format
 The ability to send payload data (e.g. from files) along with instructions to the server
 Receiving and interpreting responses from the server, and reporting these to the user, e.g. as
HTML, plain text, ASCII Art, PDF, graphic image etc.
 Dealing with error conditions reported from the server, or any protocol violations.
*
If a team consists of five members, then the extra team member must develop their own additional
client-side component. In this case each client-side component should be independent and provide
alternative mechanisms of interacting with the user. e.g. one client may use a menu system on a
terminal, whereas another may take input from a text file containing an ordered list of instructions,
then generate the output to files as HTML.
